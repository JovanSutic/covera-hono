### Step 1.5 — Test `GET /assets/types`

**Touch.** `src/modules/assets/assets.test.ts` (edit)

**Do.**

Change the `vi.hoisted` destructure to add a mock. It currently destructures
`mockGetByApartmentId, mockCreate, mockDelete, mockCheckExistence, mockAssertCanModifyAsset, mockAssertCanModifyApartmentShots` —
add `mockGetAllTypes` to both the destructure and the returned object, with `mockGetAllTypes: vi.fn()`.

Add `getAllTypes: mockGetAllTypes,` to the `vi.mock("./assets.service", …)` factory, after
`delete: mockDelete,`.

Append this block as the **last** `describe` inside the top-level `describe("Assets routes", …)`,
after the closing `});` of `describe("DELETE /assets/:id", …)`:

```ts
  describe("GET /assets/types", () => {
    const mockAssetTypes = [
      { id: VALID_ASSET_TYPE_ID, code: "COFFEE_MACHINE", category: "APPLIANCES_SMALL" },
      { id: VALID_UUID, code: "SMART_LOCK", category: "ELECTRONICS" },
    ];

    it("should return the asset type catalog ordered A-Z by code", async () => {
      mockGetAllTypes.mockResolvedValue(mockAssetTypes);

      const res = await testApp.request("/assets/types", {
        headers: { Authorization: MOCK_JWT },
      });

      expect(res.status).toBe(200);
      const data = await res.json();

      expect(Array.isArray(data)).toBe(true);
      expect(data).toHaveLength(2);
      expect(data.map((t: { code: string }) => t.code)).toEqual([
        "COFFEE_MACHINE",
        "SMART_LOCK",
      ]);
      expect(data[0].code <= data[1].code).toBe(true);
    });

    it("should be reachable and not shadowed by the /{id} route", async () => {
      mockGetAllTypes.mockResolvedValue([]);

      const res = await testApp.request("/assets/types", {
        headers: { Authorization: MOCK_JWT },
      });

      expect(res.status).toBe(200);
      expect(await res.json()).toEqual([]);
      expect(mockGetAllTypes).toHaveBeenCalledTimes(1);
    });

    it("should return 401 with the canonical envelope if the token is missing", async () => {
      mockGetUser.mockResolvedValue({
        data: { user: null },
        error: new Error("Missing token"),
      });

      const res = await testApp.request("/assets/types");

      expect(res.status).toBe(401);
      const body: any = await res.json();
      expect(body.success).toBe(false);
      expect(body.error.code).toBe("AUTH_TOKEN_MISSING");
      expect(body.error.message).toMatch(/Authentication is required/);
      expect(mockGetAllTypes).not.toHaveBeenCalled();
    });

    it("should return 403 FORBIDDEN_ROLE for a guest", async () => {
      setTestUser("guest");
      mockedUserService.getByAuthId.mockResolvedValue({
        id: VALID_UUID,
        authId: VALID_UUID,
        role: "guest",
        status: "confirmed",
      });

      const res = await testApp.request("/assets/types", {
        headers: { Authorization: MOCK_JWT },
      });

      expect(res.status).toBe(403);
      const body: any = await res.json();
      expect(body.error.code).toBe("FORBIDDEN_ROLE");
      expect(body.error.message).toMatch(/only available to: admin, host/);
      expect(mockGetAllTypes).not.toHaveBeenCalled();
    });
  });
```

`mockGetUser` and `mockedUserService` already exist in this file (used by the 401/403 cases above) —
use them, do not redeclare.

## Phase 1 invariants

- [ ] The route declares 401, 403 and 500 — the statuses `authGuard` + `rolesGuard` imply
- [ ] No new `code` is introduced; all four come from `ERROR_REGISTRY`
- [ ] No message contains an id, driver text, or table/column name
- [ ] The response is a bare array, not wrapped in `data` or `{ items, total }`
- [ ] The ordering is `orderBy(asc(assetTypes.code))` in the service — no `.sort()` anywhere
- [ ] `getByApartmentId`, `create` and `delete` are behaviourally unchanged
